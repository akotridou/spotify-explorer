# 🎵 Spotify Artist Explorer

A small frontend project inspired by Spotify's music exploration experience.

> **Note:** This project is not a Spotify clone and is not connected to the Spotify API. It is a small personal project inspired by Spotify's design and concept of exploring artists, albums, and tracks.

## ✨ Features

- 🔎 Search for artists
- 🎤 Explore artist information
- 💿 Browse albums and EPs
- 🎵 View tracks from each album
- ⚡ Quick-search buttons for available artists
- 📱 Responsive design
- 🎨 Dark, Spotify-inspired interface
- 🖼️ Artist and album artwork

## 🎯 About the Project

The goal of this project was to practice JavaScript and DOM manipulation by creating a small interactive music exploration application.

Users can search for artists included in the project's dataset and explore their albums and tracks through a simple and responsive interface.

The project uses locally defined data rather than an external music API.
